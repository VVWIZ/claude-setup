# Серия Edit может молча оборваться — верифицировать grep-ом по маркерам

**Extracted:** 2026-07-24
**Context:** Пакет из нескольких Edit по скиллам/CLAUDE.md в рамках одной задачи. Последний Edit упал с `AbortError: Tool permission stream closed before response received`, затем произошла перезагрузка VSCode.

## Problem

При серии правок через Edit одна из них может завершиться **abort'ом** (закрытие permission-стрима, перезагрузка IDE посреди задачи). Симптомы коварны:

- Успешные Edit отдают «file updated», и легко решить, что весь пакет применился.
- Упавший Edit не оставляет следа в файле — правка просто **не доехала**, без явной ошибки в итоговом состоянии.
- После перезагрузки VSCode контекст сессии восстанавливается, но **фактическое состояние файлов нужно перечитывать** — доверять «в прошлый раз я это отредактировал» нельзя.

Итог: часть задуманных изменений отсутствует, а по логу выглядит как «всё сделано».

## Solution

После **любой серии** правок в мета-файлы (или после перезагрузки/сбоя посреди работы) — **один Grep по уникальным маркерам** всех правок разом, `output_mode: content` с `-n`. Каждая правка должна вносить узнаваемую строку-маркер (название новой секции, флаг, характерная фраза).

- Grep пусто / меньше маркеров, чем правок → правка не доехала → доделать ровно недостающие.
- Не полагаться на «Edit вернул success» как на доказательство целостности всего пакета — success по каждой правке ≠ пакет целостен, если последняя оборвалась.

## Example

```
# После 4 правок с маркерами: "Режим слепого жюри", "REVIEW: PASS", "Retry с причиной", "--jury"
Grep(pattern="Режим слепого жюри|REVIEW: PASS|Retry с причиной|--jury",
     path="C:\\Users\\Arys\\.claude", glob="**/*.md",
     output_mode="content", -n=true)
# Считаешь совпадения по каждому маркеру → если какого-то нет, та правка упала → повторить только её
```

## When to Use

- Любая серия из 2+ Edit по скиллам / CLAUDE.md / промптам / конфигам
- Возобновление работы после перезагрузки IDE или abort'а инструмента посреди задачи
- Симптом-триггер: `AbortError: Tool permission stream closed`, «была перезагрузка, проверь что не потерялось»
- Смежно с `/verification-before-completion`: не говорить «готово», пока grep не подтвердил все маркеры
