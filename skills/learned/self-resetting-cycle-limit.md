# Само-обнуляющийся лимит «N напоминаний за цикл»

**Extracted:** 2026-07-07
**Context:** Baby Tracker, движок напоминаний (app/services/smart.py, nudges.py). Нужно капнуть число напоминаний за «цикл» (окно бодрствования / период простоя) без отдельной таблицы состояния.

## Problem
- Требование: «не больше N за цикл; если пользователь так и не выполнил действие — перестать слать», при этом счётчик должен сам обнуляться, когда действие выполнено (начинается новый цикл).
- Хранить счётчик/last_reset в отдельном поле — лишнее состояние и риск рассинхрона.

## Solution
Напоминания и так персистятся строками-маркерами (`Reminder`: `child_id`, `kind`, `fire_at`, `sent=True`). Лимит выражаем запросом по этим же маркерам, без нового состояния:
1. `cycle_start` = время последнего релевантного события (последний сон/стул/прогулка) или `child.created_at`, если события ещё не было.
2. `count = SELECT count(*) FROM reminders WHERE child_id=? AND kind=? AND fire_at >= cycle_start`.
3. `if count >= N: skip`.

Когда пользователь выполняет действие → появляется новое событие → `cycle_start` сдвигается вперёд → старые маркеры выпадают из окна → счёт = 0 → новый цикл стартует сам. Никакого явного сброса.

Порядок гейтов: ставить ПОСЛЕ дневного/часового дедупа. Дедуп даёт «не чаще раза в день/час», этот лимит — «не больше N за весь цикл».

## Example
```python
cycle_start = last.started_at if last else child.created_at
sent = (await session.execute(
    select(func.count()).select_from(Reminder).where(
        Reminder.child_id == child.id, Reminder.kind == "nudge:stool",
        Reminder.fire_at >= cycle_start,
    ))).scalar_one()
if sent >= MAX_PER_CYCLE:
    return None  # лимит за цикл исчерпан
```

## When to Use
- Нужен потолок на число нотификаций за эпизод/период, авто-сбрасываемый по действию пользователя.
- Маркеры уведомлений уже персистятся (есть таблица reminders/notifications со временем и типом).
- В проекте применён к «долго не спит» (3/окно бодрствования, `cycle_start` = пробуждение = `last_sleep.ended_at`) и стул/прогулка (3/цикл, `cycle_start` = последняя запись стула/прогулки).
