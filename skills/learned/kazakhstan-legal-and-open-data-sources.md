# Первоисточники законодательства и открытых данных РК

**Extracted:** 05.08.2026
**Context:** Работа с казахстанским правом, госреестрами и открытыми данными

## Problem

Поиск норм права РК и государственных данных выдаёт много вторичных пересказов
и агрегаторов. Первоисточники неочевидны, часть ссылок редиректит, часть за пейволлом,
а один из международных источников по РК формально существует, но пуст.

## Solution

### Законодательство

| Ресурс | Статус | Примечание |
|---|---|---|
| **adilet.zan.kz** | Первоисточник НПА | Полная база актов. Есть **RSS новых документов**: `/rus/docs/rss`, `/kaz/docs/rss`. Указы о назначениях и освобождении от должности публикуются отдельными документами — прямой источник актуальных должностей чиновников |
| **online.zakon.kz** | **Отдаёт 301 на prg.kz** | При WebFetch будет редирект на другой хост — повторять запрос уже на `prg.kz` |
| **prg.kz** (ИС «Параграф») | Второй независимый источник текстов | Часть контента бесплатна (кодексы, законы), персональные справки и раздел InfoWho за подпиской |

Для проверки нормы удобно брать **adilet.zan.kz + prg.kz** как два независимых источника
одного документа.

### Открытые данные и реестры

| Ресурс | Доступ | Есть ИИН/БИН |
|---|---|---|
| **data.egov.kz** | Официальный REST API v4, ключ через «Кабинет разработчика» самостоятельно. robots.txt краулинг разрешает | Частично |
| **Реестр должников** (aisoip.adilet.gov.kz) | Зеркалируется на data.egov.kz как датасет — **bulk через официальный API** | **Да** — редкий случай |
| **goszakup.gov.kz** | REST v3 + GraphQL (`ows.goszakup.gov.kz/help/v3/schema/`). Токен **по письменному запросу** в АО «Центр электронных финансов», живёт год | В реестре недобросовестных поставщиков — да |
| **ГБД ЮЛ** (реестр юрлиц) | **Публичного bulk-пути нет.** stat.gov.kz требует личный кабинет, egov — разовая справка через ЭЦП | БИН да, ИИН учредителей — нет |
| **office.sud.kz / sud.gov.kz** | Только веб-форма. **Акты обязательно обезличиваются** перед публикацией | Маловероятно |
| **OpenCorporates** | **По РК загружено 0 компаний** — не использовать | — |

### Коммерческие агрегаторы по КЗ

Kompra.kz (есть задокументированный API), Adata.kz, Kiberon.kz, Statsnet — все построены
вокруг поиска по БИН/ИИН для проверки контрагента. Физлицо у них — набор риск-флагов
(задолженности, исполнительные производства, невыездные), **не биография**.

Важно: личный аккаунт такого сервиса даёт право пользоваться сервисом, но не лицензию
строить на его данных продукт и не переносит правовую ответственность на лицензиара.

### Ключевые нормы о персональных данных

Закон РК №94-V «О персональных данных и их защите» (adilet.zan.kz/rus/docs/Z1300000094):

- **Ст. 7 п. 11** — запрет сбора и обработки ПД «для создания или расширения баз данных
  посредством нецелевого извлечения персональных данных из общедоступных источников».
  Ключевой для любого агрегирующего продукта.
- **Ст. 12 п. 2** — хранение ПД в базе на территории РК (локализация).
- **Ст. 6** — определение общедоступных ПД, формулировка внутренне противоречива
  («свободный доступ с согласия субъекта»), самостоятельным основанием не является.
- **Ст. 16** — трансграничная передача. Официального перечня стран с адекватной защитой
  найти не удалось.

### Имена

Латиница в РК официально **не введена** (четыре итерации с 2017, на 2026 не утверждена) —
имена в документах кириллицей, канонического латинского написания нет. Готовых библиотек
транслитерации и fuzzy-матчинга под казахский нет: `cyrtranslit` явно не поддерживает
казахский, казахского фонетического алгоритма не существует. Wikidata хранит мультиязычные
алиасы персон — полезный источник связок написаний через бесплатный SPARQL.

## When to Use

- Нужен текст закона или подзаконного акта РК
- Нужны данные о казахстанских юрлицах, должностных лицах, госзакупках
- Проверка контрагента или должностного лица в Казахстане
- Задача с персональными данными граждан РК — обязательно свериться со ст. 7 п. 11 и 12
- Обработка казахских имён, транслитерация, поиск по ФИО
